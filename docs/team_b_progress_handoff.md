### Be careful with

#### `speech_action_agreement`

The original Team B role mentions `speech_action_agreement`.

In V2, this metric should not be treated as valid unless it is reimplemented. The old version used an English keyword classifier and was not appropriate for Korean/free-form outputs. V2 removed it from default reporting.

If Report #2 discusses it, use this wording:

> The previous speech-action agreement metric was excluded from the primary V2 analysis because its keyword classifier was not valid for the output language and format. A future version should replace it with Korean-compatible manual or classifier-based annotation.

#### Distribution shift

Distribution shift can be useful descriptively, but do not overinterpret it as causal proof. It should support, not replace, alignment/mixed-effects analysis.

## Report #2 Suggested Structure

### Methods

Include:

- model name
- personas
- scenario/action setup
- five final conditions
- log-likelihood action selection
- chance baseline
- scenario-cluster bootstrap
- mixed-effects logistic regression

Suggested wording:

> We replaced free-form generation parsing with a closed-set action scoring procedure. For each scenario, the model received the scenario prompt and each candidate action description was scored by conditional log-likelihood. The selected action was the candidate with the highest normalized log-likelihood. This removed parse failures from the primary endpoint, but the resulting metric should be interpreted as forced-choice action-description preference rather than unconstrained generation behavior.

### Results

Include:

- parse_ok = 100 percent
- unknown = 0 percent
- AS-only improves over neutral
- prompt-only is strongest
- prompt+AS does not improve over prompt-only
- scenario variance supports cluster-aware statistics

Suggested wording:

> In the V2 closed-set evaluation, all outputs were parse-valid, eliminating the unknown-rate confound observed in the legacy generation pipeline. AS-only improved alignment over neutral, with especially clear gains for cooperative targets. However, prompt-only produced the highest alignment rates overall, and prompt+AS did not show an additional improvement over prompt-only under the selected alpha/layer setting.

### Limitations

Include:

- forced-choice loglik is not open-ended behavior
- description wording may affect loglik
- prompt ceiling effect
- no negative controls yet
- no held-out split yet
- action labels need validation
- contrastive pair quality should be audited

Suggested wording:

> The V2 results should be interpreted as evidence that activation steering changes forced-choice action-description preferences, not as definitive evidence of open-ended NPC behavior change. The analysis also lacks random, zero-hook, and wrong-vector controls, so persona-specificity remains to be tested. In addition, vector extraction and evaluation currently use the same scenario universe, so held-out validation is required before making stronger generalization claims.
